# Задача 1
## Планирование: анализ, идентификация проблем и поиск решений

### Существующие и потенциальные проблемные места
- Ручное тестирование и отсутствие автоматизации
- Отсутствие масштабирования сервисов при нагрузках
- Отсутствие кэширования
- Отсутствие репликации и шардирования БД, возможность утери данных
- Нехватка сотрудников и bus factor: по одному сотруднику на C#, React, тестирование, DevOPS
- Ручное обновление Realease и Dev-окружений, отсутствие Kubernetes и Feature Toggles
- Задержки релизов
- Ограниченное логгирование и отсутствие трассирования
- Отсутствие репликации брокера RabbitMQ 

### Инициативы в порядке приоритета
1. Достижение Observability для оценки результатов после реализации других инициатив: мониторинг, трейсинг, логгирование
2. Добавление кэширования Redis
3. Добавление реплик БД для ускорения операций чтения
4. Найм новых сотрудников для ускорения разработки и перехода на микросервисы: C#, Vue, React, DevOps
5. Повышения квалификации сотрудников перед переходом на Kubernetes
6. Автоматизация тестирования
7. Настройка ELK, Prometheus и Grafana для контроля за работой сервисов и подготовка к переходу на Kubernetes  
8. Перевод ShopApi, CrmApi, MesApi на Kubernetes с использованием Feature Toggles и возможность масштабирования при нагрузке
9. Усовершенствование CI/CD: автоматические полные и частичные релизы

### Архитектура в ближайшие полгода
- Добавлено кэширование Redis
  - Добавление Redis не потребует серьезных изменений и реализуемо с текущей командой
- Добавлены реплики БД
  - Настроены и подключены реплики БД, ускорены операции чтения. Реализуемо с текущей командой
- Ведётся найм новых сотрудников и повышение квалификации старых
  - Переход на Kubernetes потребует повышение числа сотрудников и их квалификации
- Настроены автоматические тесты, немного усовершенствован CI/CD
  - Тестер после повышения квалификации настроит автотесты 
- Настроены мониторинг, трейсинг, логгирование. Используются ELK, Prometheus, Grafana
  - Перед переходом на Kubernetes, нужно обеспечить возможность отслеживать работу системы

По приблизительной оценке, за полгода можно успеть только, что указано в списке выше
